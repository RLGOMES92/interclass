# Interclasse Porto Seguro 2026

Portal web desenvolvido para apresentação de informações relacionadas a um evento escolar.

## Recursos identificados
- Navegação por abas
- Área de conteúdo
- Seção de jornal
- Interface responsiva
- Animações de transição
- Interface visual em estilo dark/glass

## Tecnologias
- HTML
- Tailwind CSS
- Font Awesome
- Playfair Display
- Inter
