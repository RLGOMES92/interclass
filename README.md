# Interclasse Porto Seguro 2026 — Portal de Evento

Portal web desenvolvido para centralizar informações de um evento escolar em uma experiência visual, responsiva e organizada.

## 🎯 Problema de negócio

Eventos precisam concentrar programação, conteúdos, notícias e informações importantes em um único ponto de acesso, especialmente para usuários em dispositivos móveis.

## 💡 Solução

Um portal responsivo com navegação por abas, conteúdo editorial e identidade visual própria, criando uma experiência digital dedicada ao evento.

## ✨ Funcionalidades

- Navegação por abas
- Áreas de conteúdo
- Seção de jornal
- Interface responsiva
- Animações de transição
- Visual dark/glass
- Tipografia personalizada

## 🧩 Tecnologias

- HTML
- Tailwind CSS
- Font Awesome
- Playfair Display
- Inter

## 💼 Aplicações comerciais

O mesmo conceito pode ser adaptado para:

- Eventos escolares
- Eventos corporativos
- Festivais
- Conferências
- Campeonatos
- Feiras e experiências presenciais

## 🚀 Evolução possível

O projeto pode receber inscrições, programação dinâmica, notificações, formulários, integração com WhatsApp, painel administrativo e recursos de IA para atendimento aos participantes.
